# Driveexa

Driveexa is a car rental management app built with Expo, React Native, Expo Router, and TypeScript. It helps manage a local rental workflow, including vehicles, customers, bookings, payments, reports, profile settings, and email OTP based password reset.

The app stores operational data in a local SQLite database on the device and uses SecureStore on native platforms for sensitive auth session data. It supports Android, iOS, and web through Expo, with mobile as the primary target.

For a detailed project explanation, codebase structure, app usage, database overview, and cross-platform notes, see [PROJECT_GUIDE.md](PROJECT_GUIDE.md).
