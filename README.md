
# 🚗 Driveexa — Car Rental Mobile App

**Driveexa** is a cross-platform car rental mobile application built with **React Native and Expo**. It is designed to help car rental businesses provide customers with a simple and modern way to browse vehicles, view car details, and manage rental bookings.

## 📱 About the Project

Driveexa is a mobile solution for car rental businesses that want to provide their customers with a convenient digital booking experience.

The application is built for **Android and iOS** using React Native and Expo, allowing the same codebase to support both platforms.

## ✨ Features

* 🔐 User authentication
* 🚗 Browse available cars
* 🔎 Search and filter vehicles
* 📋 View detailed vehicle information
* 📅 Car rental booking
* 👤 User profile
* 🧭 Mobile navigation
* 📱 Responsive mobile interface
* 🔄 Reusable React Native components

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Expo CLI
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/sohailmunirofficial/driveexa.git
```

Open the project:

```bash
cd driveexa
```

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

You can then run the application on an Android device, iOS device, emulator, or simulator.
